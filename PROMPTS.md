# Evidencia de uso de IA y Vibe Coding

Este archivo resume los prompts, decisiones y herramientas usadas para construir el portfolio personal con apoyo de IA.

## Prompt de planificacion

> Planifica una pagina web personal tipo CV/Portfolio, usando HTML, CSS y JavaScript, que cumpla con la rubrica de Desarrollo Web Personal con Vibe Coding. Debe incluir nombre completo, fotografia personal, carrera, descripcion, habilidades, intereses, contacto, redes sociales, diseno responsive, estilos personalizados, publicacion en Netlify y evidencias del uso de IA.

## Prompt de personalizacion

> Crear un portfolio para Diego Gabriel Cortez Loayza, estudiante de Negocios Digitales, con perfil enfocado en inteligencia artificial aplicada, fine tuning, Hugging Face, inferencia, modelos locales, Linux, redes, IoT, homeservers, impresion 3D, proyectos maker, SaaS y automatizacion para pymes.

## Prompt de calidad visual

> Hacer que el sitio sea visualmente profesional, innovador y memorable: usar una identidad fuerte inspirada en amarillo y violeta, animaciones sutiles, fondo interactivo, tarjetas modernas, estructura clara, responsive design y contenido organizado.

## Prompts para imagenes generadas

> Generar una imagen editorial tecnologica sobre laboratorio de inteligencia artificial, modelos open weights, entrenamiento con GPU, curacion de datos e inferencia, con estilo oscuro profesional y acentos cyan, violeta, amarillo y verde.

> Generar una imagen editorial sobre homeserver personal, servicios locales, almacenamiento, red domestica y luces de estado, con estetica limpia, tecnica y profesional.

> Generar una imagen editorial sobre transformacion digital para negocios locales: dashboards SaaS, aplicaciones moviles, automatizacion, clientes, stock y asistente IA, sin texto legible ni marcas.

> Generar una imagen editorial que conecte agricultura, vida rural, maker culture, IoT, impresion 3D, sensores y hardware, con un taller practico cerca de un invernadero.

## Uso de OpenAI Codex

- Interpretacion de la rubrica y conversion a una estructura web concreta.
- Generacion y mejora de HTML, CSS y JavaScript.
- Revision de contraste, responsive design y coherencia visual.
- Generacion de imagenes complementarias para las secciones.
- Preparacion de evidencias, README y entregable final.

## Tecnologias usadas

- HTML para estructura semantica.
- CSS para identidad visual, responsive design y animaciones.
- JavaScript para canvas interactivo y navegacion activa.
- OpenAI Codex como herramienta principal de Vibe Coding.
- Generacion de imagenes con IA para reforzar contenido visual.
- Netlify para publicacion web.
