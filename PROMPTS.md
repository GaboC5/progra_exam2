# Evidencia de uso de IA y Vibe Coding

Este archivo documenta prompts y decisiones usadas para crear el portfolio con apoyo de OpenAI Codex.

## Prompt inicial de la tarea

> Planifica una pagina web personal tipo CV/Portfolio, usando HTML, CSS y JavaScript, que cumpla con la rubrica de Desarrollo Web Personal con Vibe Coding. Debe incluir nombre completo, fotografia personal, carrera, descripcion, habilidades, intereses, contacto, redes sociales, diseño responsive, estilos personalizados, publicacion en Netlify y evidencias del uso de IA.

## Prompt de personalizacion

> Crear un portfolio para Diego Gabriel Cortez Loayza, estudiante de Negocios Digitales, con perfil enfocado en inteligencia artificial aplicada, fine tuning, Hugging Face, inferencia, modelos locales, Linux, redes, IoT, homeservers, impresion 3D, proyectos maker, SaaS y automatizacion para pymes.

## Prompt de calidad visual

> Hacer que el sitio sea visualmente impresionante, profesional e innovador: usar una identidad fuerte inspirada en amarillo y violeta, animaciones sutiles, fondo interactivo, tarjetas modernas, estructura clara, responsive design y contenido creible.

## Uso de IA durante el proceso

- OpenAI Codex ayudo a convertir la rubrica en una arquitectura concreta de secciones.
- Codex genero estructura HTML semantica, estilos CSS personalizados y JavaScript interactivo.
- Codex propuso textos profesionales y coherentes a partir de ideas personales.
- Codex preparo una verificacion automatizada para revisar que HTML, CSS, JavaScript, Netlify y evidencias esten presentes.

## Herramientas y tecnologias

- HTML para estructura semantica.
- CSS para identidad visual, responsive design, animaciones y accesibilidad.
- JavaScript para canvas interactivo, navegacion activa, tema claro/oscuro y carga de foto.
- Netlify para publicacion web.
